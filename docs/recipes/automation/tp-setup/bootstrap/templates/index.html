Platform Automation Hub

Comprehensive automation platform for platform provisioning, configuration, deployment, and lifecycle management.

Full Documentation

DataPlane Management

  • Create & configure Kubernetes DataPlanes
  • Control Tower (BMDP) deployment
  • Automated helm chart execution
  • Lifecycle management (create, update, delete)

Observability

  • Global observability setup (Logs, Metrics, Traces)
  • DataPlane-level configuration
  • Widget dashboard integration
  • Business Activities monitoring
  • In-Product activation support

Capability Provisioning

  • BWCE / BW5CE (BusinessWorks)
  • Flogo (Lightweight microservices)
  • EMS (Enterprise Message Service)
  • Pulsar, Hub, and more

Application Deployment

  • Build & deploy BWCE/BW5CE/Flogo apps
  • Upload custom or use default app files
  • Environment configuration & endpoints
  • Automated testing with Swagger API

User Management

  • Automated user activation
  • Subscription creation
  • OAuth token generation
  • Permission assignment

CLI Integration

  • DataPlane ops (list/register K8s & Control Tower/unregister)
  • Resource management (Storage/Ingress/Activation Server)
  • Capability provisioning with auto-resource creation
  • App lifecycle (list/build/deploy/delete)
  • Advanced Mode for granular control
  • One-click save to localStorage

Advanced Features

Intelligent Automation: Conditional field display, auto-population, multi-window support, Advanced Mode CLI workflows
Debugging: Step-by-step logging, screenshot capture, Playwright trace recording
Version Compatibility: CP 1.3, 1.4, 1.5, 1.6, 1.7+ support
Environment Flexibility: Custom KUBECONFIG, local/container deployment, cloud connectivity
CLI Architecture: Object-oriented CLI wrapper with facade pattern, automatic resource creation, JSON payload editors

Quick Start

  1. Select your task from the GUI Automation or CLI Commands tab
  2. Configure environment variables as needed (most have smart defaults)
  3. Click "Run Automation" and monitor real-time progress
  4. Review results with console output, screenshots, and traces
